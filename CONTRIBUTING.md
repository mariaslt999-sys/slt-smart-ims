# Contributing to SLT Smart IMS

Thank you for your interest in contributing to **SLT Smart IMS** (Open-Source 2-Way Google Sheets & WooCommerce Inventory Management System)!

## How to Contribute
1. Fork the repository (https://github.com/mariaslt999-sys/slt-smart-ims).
2. Create a feature branch (git checkout -b feature/your-feature-name).
3. Commit your changes (git commit -m "Add feature").
4. Push to the branch (git push origin feature/your-feature-name) and open a Pull Request.

## Code Standards
- WordPress PHP Coding Standards for slt-smart-ims.php.
- Google Apps Script V8 runtime standards for SLT_Google_Sheets_TwoWay_Sync.gs.
- Never commit private API keys or sensitive Google Sheet IDs.
